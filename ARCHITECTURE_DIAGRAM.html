Legend & Quick Reference

Frontend Angular single-page app on :4200. Auto-reloads on file changes. Communicates exclusively through API Gateway.
API Gateway Reverse-proxy on :8000. Routes /api/{service}/* to internal services. Handles CORS for localhost:4200.
Microservices Independent FastAPI apps (8001–8005). Each has own SQLite DB, models, schemas. Referral Service calls Doctors & Notification.
Docker Network Internal docker-compose network. Services reach each other by hostname (e.g., http://doctor-service:8002).
Database SQLite files (not in git). Auto-created per service. Seeded with test data on first run via seed.py.
Development Start all: ./start_all.sh. Stop: ./stop.sh. Logs: docker compose logs -f

⚠️ Failure Mode: Referral Service Down

If Referral Service (8003) is down:

✗ Users cannot create/view referrals (404 on /api/referrals)

✗ Recovery: docker compose restart referral-service

Note: Referral Service requires Doctors (8002) and Notification (8005) to be healthy for new referrals to be created.
